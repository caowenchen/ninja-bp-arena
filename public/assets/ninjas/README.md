# 忍者头像资源目录

把自定义的忍者头像放进本目录，然后在忍者 JSON 中以本地路径引用：

```json
{
  "id": "naruto-001",
  "name": "漩涡鸣人",
  "avatar": "/assets/ninjas/naruto-sage.webp",
  "quality": "S",
  "tags": ["近战", "突进"],
  "enabled": true
}
```

## 命名与格式建议

- 文件名使用忍者英文/拼音小写 + 连字符，例如：`naruto-sage.webp`、`sasuke-example.webp`
- 推荐格式：**WebP**（也可用 PNG / JPG）
- 推荐尺寸：**正方形 256×256** 或 **512×512**
- 单张图片尽量控制在 100KB 以内，保证 BP 页面在手机上流畅
